# 日文歌練習室

整理「想唱／會唱的日文歌」，並提供放大版歌詞練習畫面的網頁小工具：假名標注（ふりがな）、多人合唱分色、動態歌詞、音檔與影片播放、匯出 PDF。

- 一個 HTML 檔就能用，**沒有帳號、沒有伺服器**，資料存在你自己的瀏覽器裡。
- 另有離線的**打軸工具**（Mac／Windows），可以自動產生歌詞時間軸初稿與導音版。

> 這是個人業餘作品，有需要請自行聯繫作者；沒辦法保證回覆，請見諒。

## 怎麼用

**直接開啟（建議，電腦與手機都適用）：<https://arcticfox-arcticfox.github.io/uta-note-web/>**

- 用瀏覽器開啟即可（Chrome、Edge、Safari 16.2+、Firefox 113+）。手機可以「加到主畫面」，開啟時是全螢幕、沒有網址列。
- 第一次開啟會自動跳出使用教學導覽；之後可以按左側面板的「使用教學」重看。第一次使用時會有範例歌「伯方の塩」可以練習操作。

**下載單檔使用（進階）**：到 [index.html](index.html) 按「Download raw file」存檔，雙擊就能開啟，不需要網路伺服器（但仍然需要網路載入版面與函式庫）。

### 要知道的事

- **資料只存在這個瀏覽器、這個網址**：換瀏覽器、換電腦，或改用不同的開啟方式（網頁與下載的檔案）都看不到原本的資料。請定期用「匯出」存成 CSV 備份，要搬資料就用「匯入」。
- **需要網路的部分**：版面框架與 PDF 匯出的函式庫從網路載入，自動標注假名第一次也要下載日文辭典，所以沒有網路時打不開。
- **音檔不會被複製進瀏覽器**：只記路徑或網址。手機瀏覽器與電腦能播放的格式也不同。
- **手機是看歌詞用的畫面**：編輯歌詞、打軸、匯出 PDF 請在電腦上做。

## 主要功能

**歌曲與歌詞**
- 「我的歌庫」「許願歌單」兩個歌單，可搜尋、依歌手／標籤篩選、釘選常練的歌。
- 每首歌記歌名、歌手、Joysound／DAM 編號、伴唱帶網址、歌詞、備註與標籤。
- 歌詞用簡單的文字語法標假名（`字[假名]`），可以點畫面上的字修改，也可以自動標注。

**練習畫面**
- 歌詞字級、假名顯示／隱藏、行距都可以調整，選擇會記住。
- 多人合唱分色：每首歌自訂角色與顏色，用 `角色名稱: 歌詞` 標記是誰唱，支援多人同唱。
- 動態歌詞：播放時歌詞跟著高亮並自動捲動；可以自己打軸、匯入 LRC、調整偏移；單句、A-B、整首重複播放。

**播放**
- 本機音檔，以及 YouTube、bilibili、niconico、Google 雲端硬碟、影片檔網址的嵌入播放（浮動視窗）。
- 練習歌單與連播：隨機、循環、間歇。
- 混音鈕：在原曲與無人聲版本之間一鍵切換（預設隱藏，到「顯示」選單打開）。

**匯入匯出**
- CSV 匯出／匯入（含角色、音檔清單、時間軸）；匯入遇到重複的歌會逐首詢問。
- PDF 匯出（含假名與分色，可選雙欄與橫向）。

## 打軸工具（Mac／Windows）

在你的電腦上離線執行：去除人聲、把你自己的歌詞逐行對到時間上，產生 `.lrc`（打軸初稿）與人聲壓低的導音版；另有錄音混音與 LRC 編輯。**輸出是初稿，匯入後請自己聽過再修。**

- **下載**：到 [Releases](../../releases)，Mac（Apple 晶片）下載 `uta-note-auto-timing-v版本-mac.zip`，Windows（64 位元）下載 `uta-note-auto-timing-v版本-win.zip`。
- 解壓縮後開啟「打軸.command」（Mac）或「打軸.bat」（Windows），第一次會自動安裝環境（約 1.5GB，需要網路）；操作請看資料夾裡的「使用教學.html」。
- 不支援 Intel Mac；目前只有日文歌驗證過。

## 關於歌詞

這個工具不內建任何歌曲歌詞或音檔，也不提供下載。歌詞與音檔請自行準備，並注意著作權。
