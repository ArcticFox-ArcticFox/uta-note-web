# 日文歌練習室

整理「想唱／會唱的日文歌」，並提供放大版歌詞練習畫面的網頁小工具：假名標注（ふりがな）、多人合唱分色、動態歌詞、音檔與影片播放、匯出 PDF。

- 一個 HTML 檔就能用，**沒有帳號、沒有伺服器**，資料存在你自己的瀏覽器裡。
- 另有離線的**打軸工具**（Mac／Windows），可以自動產生歌詞時間軸初稿與導音版。

> 這是個人業餘作品，有需要請自行聯繫作者；沒辦法保證回覆，請見諒。

## 怎麼用

**直接開啟（建議，電腦與手機都適用）：<https://arcticfox-arcticfox.github.io/uta-note-web/>**

- 用瀏覽器開啟即可（Chrome、Edge、Safari 16.2+、Firefox 113+）。手機可以「加到主畫面」，開啟時是全螢幕、沒有網址列。
- 第一次開啟會自動跳出使用教學導覽；之後可以按左側面板的「使用教學」重看。第一次使用時會有範例歌「伯方の塩」可以練習操作。

**下載單檔使用（進階）**：到 [index.html](index.html) 按「Download raw file」存檔，雙擊就能開啟，不需要網路伺服器（但仍然需要網路載入版面與函式庫）。

### 要知道的事

- **資料只存在這個瀏覽器、這個網址**：換瀏覽器、換電腦，或改用不同的開啟方式（網頁與下載的檔案）都看不到原本的資料。請定期用「匯出」存成 CSV 備份，要搬資料就用「匯入」。
- **需要網路的部分**：版面框架與 PDF 匯出的函式庫從網路載入，自動標注假名第一次也要下載日文辭典，所以沒有網路時打不開。
- **音檔不會被複製進瀏覽器**：只記檔名或網址。拖曳或選過的音檔在這次開啟期間可以直接播，重新整理後要再選一次（可以用「選擇音樂資料夾…」一次選完）。手機瀏覽器與電腦能播放的格式也不同。
- **手機是看歌詞用的畫面**：編輯歌詞、打軸、匯出 PDF 請在電腦上做。

## 主要功能

**歌曲與歌詞**
- 「我的歌庫」「許願歌單」兩個歌單，可搜尋、依歌手／標籤篩選、釘選常練的歌。
- 每首歌記歌名、歌手、Joysound／DAM 編號、伴唱帶網址、歌詞、備註與標籤。
- 歌詞用簡單的文字語法標假名（`字[假名]`），可以點畫面上的字修改，也可以自動標注。

**練習畫面**
- 歌詞字級、假名顯示／隱藏、行距都可以調整，選擇會記住。
- 多人合唱分色：每首歌自訂角色與顏色，用 `角色名稱: 歌詞` 標記是誰唱，支援多人同唱。
- 動態歌詞：播放時歌詞跟著高亮並自動捲動；可以自己打軸、匯入 LRC、調整偏移；單句、A-B、整首重複播放。

**播放**
- 本機音檔，以及 YouTube、bilibili、niconico、Google 雲端硬碟、影片檔網址的嵌入播放（浮動視窗）。
- 一首歌可以放好幾個音檔版本，按 ★ 設成預設播放的版本。
- 練習歌單與連播：隨機、循環、間歇。
- 混音鈕：在原曲與無人聲版本之間一鍵切換（預設隱藏，到「顯示」選單打開）。

**匯入匯出**
- CSV 匯出／匯入（含角色、音檔清單、時間軸）；匯入遇到重複的歌會逐首詢問。
- PDF 匯出（含假名與分色，可選雙欄與橫向）。

## 使用教學導覽（v0.13.10）

第一次開啟時會自動跳出教學，依序把畫面上的按鈕框起來說明；之後隨時可以按左側面板的「使用教學」重看。電腦版 15 步，手機版 9 步（手機不能編輯歌詞，沒有的功能不列入）。下表是每一步在教什麼，以及卡片上沒寫、但常被問到的細節。

| # | 步驟 | 手機 | 在教什麼 | 補充說明 |
|---|---|---|---|---|
| 1 | 點一下可複製，按「編輯」才能改 | ✓ | 歌名、編號、網址點一下就複製；按「編輯」才能修改，改完按「儲存」 | 有沒存的修改時換歌，會先問要不要放棄 |
| 2 | 影片與音檔 | ✓ | 貼影片網址按「嵌入」或畫面底部的「▶ 影片」，在浮動視窗播放；音檔可以拖曳或點選，多個版本用 ★ 設預設 | bilibili 與 Google 雲端硬碟讀不到播放時間，不能用動態歌詞 |
| 3 | 許願歌單先收藏，想唱了再轉正 | ✓ | 想學的歌先放「許願歌單」，按 ← 搬到「我的歌庫」 | 許願歌單的歌要先搬到我的歌庫，才能加進練習歌單 |
| 4 | 練習歌單：排好順序一次連播 | ✓ | 在我的歌庫按「＋」加入，「全部播放」依序連播；隨機、循環、間歇三個開關 | 只有音檔會連播，影片不參與。用網頁版或下載的檔案時，選過的音檔這次開啟期間可以直接播，重新整理後要再選一次 |
| 5 | 貼歌詞、自動標假名 | — | 「歌詞」選單 →「編輯歌詞原始碼／匯入」，貼上歌詞，按「自動標注假名」，檢查後套用 | 第一次要下載約 20MB 的日文辭典。讀音不一定對：在歌詞上點那個字就能改假名或清掉 |
| 6 | 歌詞符號請用全形，多人同唱用 + | — | 半形的 `: ; [ ] { } \| +` 是語法符號，要當一般文字請改用全形；多人同唱寫成 `主唱A+主唱B: 歌詞` | |
| 7 | 合唱分色 | — | 先在「編輯角色」設定角色與顏色，再點歌詞旁的圓點挑角色 | 分色寫在歌詞文字裡，所以會跟著 CSV 一起匯出 |
| 8 | 動態歌詞：打軸與匯入 LRC | — | 「歌詞」選單的「動態歌詞」：邊播放邊點每一句的起點，或匯入 LRC；歌詞最後多一行空白行當結束位置 | 影片和音檔的時間對不上時，用「偏移」整份一起調，每個音檔、每個影片各自一個。已經打好的時間軸，匯入 LRC 時預設只補空白的行。也可以用打軸工具產生初稿 |
| 9 | ♪ 與 ↑ 兩顆圓鈕 | ✓ | ♪ 回到目前唱到的句子，↑ 回到歌詞最上面 | 平常只有捲離目前句（或捲離頂端）時才會出現 |
| 10 | 「顯示」選單 | ✓ | 字級、行距、假名顯示與隱藏、分色顯示（底色／文字色）；混音鈕要在這裡打開 | 這些選擇只記在這台裝置。混音鈕會在原曲與同名的伴奏檔（例如「歌名.伴奏.mp3」）之間一鍵切換，第一次按時要選檔或選一次音樂資料夾 |
| 11 | 重複播放 | — | 單句、A-B、整首 | 單句與 A-B 要先有時間軸，範圍以句子為單位 |
| 12 | 一鍵匯出 PDF | — | 「輸出」選單 →「歌詞匯出成 PDF」；雙欄、橫向在「PDF 設定」 | PDF 含假名與分色 |
| 13 | 標籤與機種收錄 | ✓ | 「編輯」裡替歌加標籤；清單上的「標籤」按鈕篩選，也有 Joysound／DAM 收錄 | 同一組內任選其一、不同組要同時符合；搜尋框也會比對標籤 |
| 14 | CSV 備份與搬家 | ✓ | 「匯出」存成檔案，「匯入」讀回來，重複的歌會逐首詢問 | 換瀏覽器、換電腦或換開啟方式時，資料只能靠 CSV 搬 |
| 15 | 關於與下載 | ✓ | 左下角「關於與下載」：授權說明與打軸工具下載 | |

### 教學沒提到的小技巧

- **手機切換畫面**：手機畫面最上方有「歌單／歌號」「練習歌詞」兩顆按鈕，一次顯示一種，會記住上次的選擇。
- **加到主畫面**：手機用瀏覽器的「加入主畫面」，之後從圖示開啟是全螢幕、沒有網址列（沒有網路時仍然打不開）。
- **搜尋與釘選**：搜尋會比對歌名、歌手與標籤，忽略空格；歌手可以複選；常練的歌釘選後排在最上面。
- **範例歌**：第一次使用時「我的歌庫」和「許願歌單」各有一首範例歌，可以拿來練習操作，不需要時直接刪除。

## 打軸工具（Mac／Windows）

在你的電腦上離線執行：去除人聲、把你自己的歌詞逐行對到時間上，產生 `.lrc`（打軸初稿）與人聲壓低的導音版；另有錄音混音與 LRC 編輯。**輸出是初稿，匯入後請自己聽過再修。**

- **下載**：到 [Releases](../../releases)，Mac（Apple 晶片）下載 `uta-note-auto-timing-v版本-mac.zip`，Windows（64 位元）下載 `uta-note-auto-timing-v版本-win.zip`。
- 解壓縮後開啟「打軸.command」（Mac）或「打軸.bat」（Windows），第一次會自動安裝環境（約 1.5GB，需要網路）；操作請看資料夾裡的「使用教學.html」。
- 不支援 Intel Mac；目前只有日文歌驗證過。

## 關於歌詞

這個工具不內建任何歌曲歌詞或音檔，也不提供下載。歌詞與音檔請自行準備，並注意著作權。
