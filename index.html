● 打軸中

可將歌詞與假名格式（例如：新[あたら]しい）貼在此處匯入，每一行代表一句歌詞。套用後將覆蓋目前的歌詞內容。
假名預設只套用在「[」前面那一個字；如果要讓假名套在一整個詞上，用大括號包住該詞，例如：{食べ物}[たべもの]。
同一行可用半形「;」切成多個分色區塊；區塊開頭寫「角色名稱:」（名稱需跟「編輯角色」裡的名稱完全一致）即可直接標色，例如：A: せーの;B: 頑張れ。多人同時唱用半形「+」連接名稱，例如：A+B: せーの。
注意：[ ] { } ; : + 這些半形符號是標記用的，歌詞本身出現時也會被當成標記——例如英文歌詞裡的「;」會把一行切成兩段、「Chorus[x2]」會變成替 s 加假名；區塊開頭的文字剛好跟某個角色名稱一樣、後面又接冒號時，也會被當成那個角色。歌詞或角色名稱裡需要用到這些符號時，請改用全形（；：［］＋），全形不會被當成標記，假名則一定要用半形 [ ]。

「自動標注假名」會辨識上面文字框裡還沒標過假名的漢字並自動加註（已經手動標好、或分色/角色標記的部分不會被覆蓋），標完仍會留在文字框裡讓你先檢查，確認沒問題再按「套用」。首次使用需要下載日文語言辭典（約 20MB），需要一點時間。
